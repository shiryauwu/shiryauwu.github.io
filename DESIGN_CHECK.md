# Сверка с Figma — 2 ноября 2026

Источник: [SoundMark, страница «макеты»](https://www.figma.com/design/3jtMRwDY88c6WF8Fspn6df/SoundMark?node-id=215-516&p=f).

Через браузер просмотрены общий холст и увеличенные экраны «Главная песни», «Карточка трека», «Профиль рецензии», «Модалка (инфа о треке)» и «Модалка (загрузить трек)». У фрейма «Главная песни» видна подпись 1440 × 1071. Инспектор свойств и просмотр прототипа требуют входа; точные значения из Figma не экспортировались.

## Исправлено после сравнения с макетом

| Область | Изменение в автономной вёрстке |
| --- | --- |
| Общая композиция | Ограничена ширина рабочего пространства, уточнены ширина и внутренние отступы бокового меню. |
| Навигация | Вместо текстового логотипа в боковом меню используется знак SoundMark. Добавлены «Подписки» и «Ещё», убрана заливка выбранного пункта. |
| Плеер | Убрана тень отдельной карточки, плеер размещён после кнопок действий, шкала расположена перед кнопками воспроизведения. |
| Лента | Убраны тени и скруглённые контейнеры публикаций, добавлены тонкие разделители, аватар слева от текста, форма публикации, действия под треком. |
| Карточка песни | Вместо большого тёмного блока — узкий цветной баннер, обложка поверх него, заголовок и оранжевые действия на белом фоне. Добавлена общая строка поиска. |
| Профиль | Вместо сплошной оранжевой карточки — узкий баннер, крупный круглый аватар с перекрытием, информация на белом фоне, вкладки музыки и рецензий. |
| Поиск | Добавлены четыре вкладки, компактные строки песен и горизонтальный ряд исполнителей. |
| Модальное окно | Заголовок «Информация о треке», слева обложка, справа поля, основная кнопка слева, очистка справа. |

## Оставшиеся отличия и границы проверки

- Это визуальное приближение по холсту Figma, а не подтверждённая копия по пикселям. Цвета, шрифты и размеры оценены визуально; точные свойства слоёв не получены.
- Сравнивались вид макета и HTML/CSS. Снимок итоговой локальной страницы не получен: встроенный браузер ранее запретил открытие `file://`. Отрисовка и мобильные размеры не проверены скриншотами; мобильная компоновка сделана отдельно.
- Сохранены демонстрационные имена, описания и локальные иллюстрации. Для большинства исполнителей используются инициалы вместо фотографий из Figma.
- Информация о файле и описание публикации объединены в одной форме; в макете это отдельные окна. Поле жанра, фото публикации, ответы на рецензии и сортировка обсуждения не перенесены.
- Стартовая страница адаптирована для входа в демонстрацию без регистрации и авторизации.
- Избранное, подписки, рецензии и добавление файла работают в памяти вкладки. Серверных действий нет.

Переходы, формы, вкладки и локальные действия проверяются отдельно от визуального соответствия. Для финальной проверки по пикселям нужны точные свойства и ассеты Figma и снимки локальной страницы при том же размере окна.
